# Cognifyz Machine Learning Internship

## 📌 About the Project

This repository contains the machine learning tasks I completed during my
Machine Learning Internship at Cognifyz Technologies.

The project demonstrates practical applications of machine learning using
Python, Pandas, and Scikit-learn on restaurant-related data.

## 🚀 Tasks Completed

### Task 1 — Predict Restaurant Ratings
- Data preprocessing and missing-value handling
- Categorical feature encoding
- Train-test split
- Random Forest Regression
- Model evaluation
- Feature importance analysis

### Task 2 — Restaurant Recommendation System
- Data preprocessing
- Cuisine feature representation
- Content-based filtering
- Cosine similarity
- Cuisine and price-range based recommendations

### Task 3 — Cuisine Classification
- Data preprocessing
- Primary cuisine extraction
- Categorical encoding
- 80:20 train-test split
- Logistic Regression
- Random Forest Classification
- Accuracy, precision and recall evaluation
- Confusion matrix analysis

## 🛠️ Technologies Used

- Scikit-learn
- Google Colab
- Jupyter Notebook
